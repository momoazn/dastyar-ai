# Persian AI Assistant

A modern web application for interacting with Ollama and Stable Diffusion AI services, featuring voice input and RTL support.

## Features

- 🤖 Ollama AI Integration
- 🎨 Stable Diffusion Image Generation
- 🎤 Voice Recording & Speech-to-Text
- 🇮🇷 Full Persian Language Support
- 📱 Responsive RTL Design

## Prerequisites

- Node.js 18+
- Ollama running locally on port 11434
- Stable Diffusion running locally on port 7860

## Setup

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

## Architecture

The application is structured into the following main components:

- `src/services/` - AI service integrations
- `src/hooks/` - Custom React hooks
- `src/components/` - UI components
- `src/utils/` - Helper functions
- `src/types/` - TypeScript type definitions
