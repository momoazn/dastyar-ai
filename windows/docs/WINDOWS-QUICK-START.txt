FIRST TIME SETUP
────────────────────────────────────────────────────────────────

1. Download Whisper Models (REQUIRED for transcription):
   → Run: download-whisper-models.bat
   → Select model (recommended: "2" for base model)

2. Configure (optional):
   → Run: configure.bat
   → Or edit config.json manually

3. Verify Installation:
   → Run: verify-installation.bat

STARTING THE APPLICATION
────────────────────────────────────────────────────────────────

→ Run: start-dastyar-ai.bat

This will:
  • Start Whisper API server (port 8080)
  • Start main server (port 3000)
  • Open browser automatically

Access: http://localhost:3000

STOPPING THE APPLICATION
────────────────────────────────────────────────────────────────

→ Run: stop-dastyar-ai.bat

Or press Ctrl+C in the start window

HELPFUL SCRIPTS
────────────────────────────────────────────────────────────────

• start-dastyar-ai.bat      - Start both services
• stop-dastyar-ai.bat       - Stop both services
• download-whisper-models.bat - Download Whisper models
• check-health.bat          - Check if services are running
• configure.bat             - Interactive configuration
• verify-installation.bat   - Verify installation

TROUBLESHOOTING
────────────────────────────────────────────────────────────────

Services won't start?
  → Check if ports 3000/8080 are in use
  → Run: check-health.bat

Whisper not working?
  → Ensure models are downloaded
  → Check models/ directory has .bin files

Need help?
  → See WINDOWS-README.md for detailed documentation
