# پیوست B: نمایه API

این پیوست نمای کلی مسیرهای سطح بالا در سرور اصلی را ارائه می‌کند.

## Mount points

- `/rpc`
- `/api/chat`
- `/api/images`

## Endpoints کمکی

- `GET /health`

## یادداشت

جزئیات دقیق قراردادهای RPC در لایه ORPC و شِماهای Zod تعریف می‌شود. برای گزارش‌های تحویلی، پیشنهاد می‌شود در کنار این نمایه، نمونه درخواست/پاسخ‌های استاندارد نیز ارائه گردد.

> توجه: مسیر `/` در سرور اصلی «endpoint سلامت» مجزا نیست. درخواست‌های `GET` خارج از `/api` و `/rpc` عمدتاً به عنوان مسیرهای رابط کاربری (SPA) از طریق `serveStatic` و fallback به `index.html` سرو می‌شوند؛ بنابراین رفتار `/` تابع وجود build وب در `WEB_DIST_DIR` است.
