04 — ساختار پروژه

پروژه یک monorepo با Bun workspace و Turbo است.

دایرکتوری ها

مسیر محتوا
apps/server/src/app.ts ساخت Hono app، CORS، security headers، routes و SPA fallback
apps/server/src/routes REST routeهای chat، images و ORPC bridge
apps/server/src/procedures ORPC procedureها برای web client
apps/server/src/repositories دسترسی به دیتابیس و queryهای مالکیت محور
apps/server/src/services auth، AI providers، پردازش فایل، storage
apps/web/src/routes TanStack Router file routes
apps/web/src/components UI primitives و feature components
apps/web/src/hooks منطق reusable برای chat، user، image، transcription
apps/whisper Go HTTP service برای Whisper
scripts build orchestration، packaging، lifecycle commandها

جریان داده اصلی

  1. کاربر در وب با React routeها کار می کند.
  2. وب برای CRUD و feature actions از ORPC client در apps/web/src/utils/orpc.tsاستفاده می کند.
  3. سرور procedure را validate می کند و auth context می سازد.
  4. Repositoryها با Drizzle/SQLite داده را می خوانند یا می نویسند.
  5. در featureهای AI، سرور provider مناسب را انتخاب و external service را فراخوانی می کند.
  6. نتیجه به وب برمی گردد و TanStack Query cache را به روز می کند.

جریان کامل بین appها

  1. Web app از طریق TanStack Query و ORPC به سرور درخواست می فرستد.
  2. Server با JWT و lookup کاربر در دیتابیس، auth context می سازد.
  3. Repository layer از SQLite با Drizzle ORM استفاده می کند.
  4. AI providerها مثل Ollama و LM Studio با APIهای OpenAI-compatible صدا زده می شوند.
  5. File upload از validation، storage، text extraction و chunk indexing عبور می کند.
  6. Whisper service transcription صوت را از طریق HTTP انجام می دهد.

Entry pointهای اصلی

بخش Entry جزئیات
Server apps/server/src/index.ts config، migration و start سرور
Server app factory apps/server/src/app.ts Hono app، middlewareها، routeها و static serving
ORPC router apps/server/src/procedures/index.ts ترکیب procedureهای API
Auth apps/server/src/services/auth.tsو middlewares/auth.ts JWT، user lookup و access control
Database apps/server/src/database/schema/index.ts schema و migrationهای Drizzle/SQLite
Web apps/web/src/main.tsx mount اپ و providerها
Web routes apps/web/src/routes/* routeهای TanStack Router
Web ORPC client apps/web/src/utils/orpc.ts client و QueryClient مشترک
Whisper apps/whisper/main.go HTTP service برای transcription
Whisper handler apps/whisper/internal/handler/transcribe.go HTTP handler آپلود/تبدیل صوت
Whisper service apps/whisper/internal/service/whisper.go ارتباط با whisper.cpp و مدل ها

مرزبندی لایه ها

  • Route/Procedure:validation، auth، شکل response، orchestration سبک.
  • Repository:SQL/Drizzle، ownership filtering، persistence.
  • Service:provider integration، پردازش فایل، storage، auth helpers.
  • Web Hook:query/mutation wiring، state و side effectهای UI.
  • Component:rendering و interaction محلی.
