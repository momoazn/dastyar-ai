
## ۳-۱۳ نیازمندی‌های سیستم و تحلیل منابع (System Requirements)

برای اطمینان از عملیاتی بودن طرح پیشنهادی، محاسبات دقیقی روی مصرف منابع انجام شده است. این محاسبات بر اساس معماری مدل‌ها و سربار سیستم‌عامل انجام شده است.

### ۳-۱۳-۱ تحلیل ریاضی مصرف حافظه (Memory Footprint Analysis)
مهم‌ترین گلوگاه در اجرای مدل‌های زبانی محلی، حافظه رم (RAM) است. فرمول تخمینی مصرف حافظه برای مدل‌های کوانتیده شده GGUF به شرح زیر است:

$$ M \approx (P \times B / 8) + K + C $$

که در آن:
*   $P$: تعداد پارامترهای مدل (مثلاً ۸ میلیارد).
*   $B$: دقت بیت‌ها (مثلاً ۴ بیت).
*   $K$: حافظه مورد نیاز برای KV Cache (بسته به طول Context Window).
*   $C$: سربار کانتکست (حدود ۵۰۰ مگابایت).

**محاسبه برای مدل Llama-3-8B-Q4_K_M:**
*   حجم فایل مدل: $8 \times 10^9 \times 4 / 8 \approx 4.8$ گیگابایت.
*   KV Cache (برای زمینه ۴۰۹۶ توکن): $\approx 1.2$ گیگابایت.
*   **مجموع مورد نیاز برای LLM:** حدود **۶ گیگابایت**.

**محاسبه برای مدل Whisper (Small):**
*   حجم مدل: ۵۰۰ مگابایت.
*   سربار پردازش صوت: ۲۰۰ مگابایت.
*   **مجموع:** ۷۰۰ مگابایت.

### ۳-۱۳-۲ جدول مشخصات سخت‌افزاری پیشنهادی

بر اساس محاسبات فوق، مشخصات زیر برای اجرای روان سیستم پیشنهاد می‌گردد:

| قطعه سخت‌افزاری | حداقل سیستم مورد نیاز (Minimum) | سیستم پیشنهادی (Recommended) | توضیحات فنی |
| :--- | :--- | :--- | :--- |
| **پردازنده (CPU)** | Intel Core i5 (Gen 8+) / AMD Ryzen 5 | Apple M1/M2/M3 یا Intel Core i7 (Gen 12+) | پشتیبانی از دستورات AVX2 برای Whisper حیاتی است. |
| **حافظه رم (RAM)** | ۸ گیگابایت | ۱۶ گیگابایت | در ۸ گیگابایت، سیستم‌عامل از Swap استفاده خواهد کرد که سرعت را کاهش می‌دهد. |
| **کارت گرافیک (GPU)** | گرافیک مجتمع (Intel UHD) | NVIDIA RTX 3060 (6GB+) | استفاده از GPU سرعت تولید متن را تا ۲۰ برابر افزایش می‌دهد. |
| **فضای ذخیره‌سازی** | ۲۰ گیگابایت SSD | ۵۰ گیگابایت NVMe SSD | سرعت خواندن مدل از دیسک (Load Time) به سرعت SSD وابسته است. |

### ۳-۱۳-۳ پیش‌نیازهای نرم‌افزاری
*   **سیستم عامل:**
    *   Windows 10/11 (بیلد ۲۰H2 به بالا).
    *   macOS Monterey (12.0) به بالا.
    *   Linux (Ubuntu 20.04+).
*   **درایورها:** نصب درایورهای NVIDIA CUDA (در صورت وجود GPU) برای شتاب‌دهی سخت‌افزاری.
