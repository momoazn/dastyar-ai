01 — راه اندازی Windows از صفر

این راهنما مسیر تحویل repo به یک توسعه دهنده را تا رسیدن به اپ در حال اجرا روی Windows توضیح می دهد. دستورها برای PowerShell نوشته شده اند.

هدف نهایی

  • وب روی http://localhost:5173اجرا شود.
  • سرور روی http://localhost:3000اجرا شود.
  • health سرور از http://localhost:3000/healthپاسخ دهد.
  • Ollama برای قابلیت های متنی آماده باشد.
  • Whisper و Stable Diffusion در صورت نیاز آماده یا آگاهانه غیرفعال باشند.

1. نصب پیش نیازهای سیستم

ساده ترین مسیر نصب روی Windows استفاده از wingetاست. اگر ماشین سازمانی wingetندارد، همان ابزارها را از وب سایت رسمی نصب کنید و بعد PowerShell جدید باز کنید.

ابزار کاربرد نصب پیشنهادی
Git دریافت repo winget install --id Git.Git -e
Bun package manager، runtime و test runner powershell -c "irm bun.sh/install.ps1 | iex"
Go ساخت و اجرای سرویس Whisper winget install --id GoLang.Go -e
Ollama مدل های chat، ترجمه، خلاصه سازی و embedding winget install --id Ollama.Ollama -e
Visual Studio Build Tools ابزار native build در صورت نیاز dependencyها winget install --id Microsoft.VisualStudio.2022.BuildTools -e

بعد از نصب، PowerShell را ببندید و دوباره باز کنید تا PATH جدید اعمال شود.

1.1 لینک و دستور نصب دستی prerequisiteها

ابزار روش جایگزین چرا لازم است
Bun https://bun.sh/docs/installation اجرای scriptها، نصب packageها، test و build.
Git https://git-scm.com/download/win clone کردن repo و ساخت archive source.
Go https://go.dev/dl/ اجرای apps/whisper.
Ollama https://ollama.com/download/windows مدل های local chat و embedding.
LM Studio https://lmstudio.ai/download جایگزین OpenAI-compatible برای مدل های local.
Automatic1111 https://github.com/AUTOMATIC1111/stable-diffusion-webui تولید تصویر با Stable Diffusion.

1.2 آماده سازی PowerShell

اگر اجرای script روی سیستم محدود شده است، PowerShell را با دسترسی عادی باز کنید و فقط برای همین session policy را آزادتر کنید: 

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

این تغییر دائمی نیست و فقط همان پنجره PowerShell را تحت تاثیر قرار می دهد.

2. دریافت repo

git clone <REPO_URL> dastyar-ai
cd dastyar-ai

اگر repo به صورت zip تحویل شده است، آن را extract کنید و PowerShell را در root پروژه باز کنید.

3. بررسی نسخه ابزارها

git --version
bun --version
go version
ollama --version

نسخه Bun باید 1.3 یا جدیدتر باشد. اگر دستور bunپیدا نشد، مسیر نصب Bun را به PATH اضافه کنید یا PowerShell را دوباره باز کنید.

4. نصب dependencyها

bun install

این دستور dependencyهای root، apps/serverو apps/webرا با workspace نصب می کند.

اگر نصب به خاطر cache یا network شکست خورد:

bun install --force

اگر پشت proxy یا registry داخلی هستید، اول تنظیمات شبکه سازمان را روی npm/Bun اعمال کنید. بعد از نصب موفق، پوشه node_modulesدر root ساخته می شود.

5. ساخت config سرور

bun run config:generate
bun run config:show
bun run config:validate

فایل runtime در apps/server/config.jsonساخته می شود و داخل git نگه داری نمی شود. برای development مقدارهای پیش فرض کافی هستند، اما برای محیط واقعی حتما JWT_SECRETرا تغییر دهید.

کلید مقدار توسعه
DATABASE_FILE ./data.db
OLLAMA_BASE_URL http://localhost:11434
WHISPER_SERVER_URL http://127.0.0.1:8080
STABLE_DIFFUSION_BASE_URL http://localhost:7860

6. آماده سازی دیتابیس

bun run db:migrate

دیتابیس SQLite محلی ساخته یا migrate می شود. برای دیدن دیتابیس:

bun run db:studio

7. راه اندازی Ollama

Ollama باید قبل از استفاده از chat و embedding در حال اجرا باشد.

ollama serve

در یک PowerShell دیگر مدل های لازم را بگیرید:

ollama pull llama3.2
ollama pull nomic-embed-text
ollama list

اگر از مدل دیگری استفاده می کنید، بعد از اجرای اپ از بخش admin یا sync مدل ها آن را به سیستم معرفی کنید.

برای تست مستقیم Ollama بدون اپ:

ollama run llama3.2 "Say ready"
Invoke-WebRequest http://localhost:11434/api/tags

8. راه اندازی Whisper اختیاری

Whisper برای transcription فایل صوتی است. اگر فعلا transcription لازم نیست، می توانید این بخش را رد کنید؛ health سرور فقط Whisper را unavailable نشان می دهد. 

bun run download:ffmpeg
bun run download:model
bun run dev:whisper

سرویس Whisper روی http://localhost:8080اجرا می شود. مدل پیش فرض ggml-base.binاست و داخل apps/whisper/modelsقرار می گیرد.

برای دانلود مدل بزرگ تر:

bun scripts/downloads/download-model.ts ggml-small.bin
bun scripts/downloads/download-model.ts ggml-medium.bin

مدل بزرگ تر کیفیت بهتر و مصرف RAM/CPU بیشتر دارد. برای onboarding سریع، همان ggml-base.binکافی است.

9. راه اندازی Stable Diffusion اختیاری

تولید تصویر به Automatic1111 WebUI نیاز دارد. اگر تصویر لازم نیست، این بخش را رد کنید.

  1. Automatic1111 WebUI را نصب کنید.
  2. آن را با API فعال اجرا کنید: webui-user.bat --api
  3. آدرس http://localhost:7860را باز کنید.
  4. اگر پورت متفاوت است، STABLE_DIFFUSION_BASE_URLرا در config تغییر دهید.

اگر فقط chat/RAG/translation را توسعه می دهید، Stable Diffusion اجباری نیست. فقط feature تصویر خطا یا unavailable نشان می دهد.

10. اجرای development

ساده ترین حالت اجرای کل workspace:

bun run dev

یا هر بخش جداگانه:

bun run dev:server
bun run dev:web
bun run dev:whisper

بعد از بالا آمدن سرویس ها:

Invoke-WebRequest http://localhost:3000/health
Start-Process http://localhost:5173

اگر bun run devخواندن logها را سخت کرد، سه PowerShell جدا باز کنید و هر سرویس را جدا اجرا کنید: server، web، whisper.

11. اولین ورود

  • وب را باز کنید: http://localhost:5173
  • اولین کاربر را ثبت نام کنید.
  • اولین کاربر به صورت خودکار admin می شود.
  • از admin/settings وضعیت featureها، مدل ها و health را بررسی کنید.

12. اجرای build ویندوز

bun run build:windows

خروجی executable ویندوز برای سرور در apps/server/distو خروجی Whisper در مسیر build مربوط به آن قرار می گیرد. برای build سریع توسعه که Whisper را رد کند: 

bun run build:fast

13. اجرای نسخه build شده

bun run start
bun run status
bun run stop

startbinaryهای build شده را اجرا می کند. قبل از آن باید build موفق انجام شده باشد.

14. چک نهایی قبل از تحویل

bun run lint:check
bun run check-types
bun run test --force
bun --cwd apps/web build
bun --cwd apps/server build
bun run archive

اگر همه دستورها pass شدند، repo برای توسعه بعدی آماده است. خروجی archive در پوشه releaseساخته می شود.

15. حداقل setup بدون سرویس های اختیاری

برای یک توسعه دهنده frontend یا backend که فعلا transcription و تصویر لازم ندارد، این حداقل کافی است: 

bun install
bun run config:generate
bun run db:migrate
ollama serve
ollama pull llama3.2
ollama pull nomic-embed-text
bun run dev:server
bun run dev:web

در این حالت Whisper و Stable Diffusion آماده نیستند، اما login، admin، chat، settings و بخش های اصلی قابل توسعه هستند.

خطاهای رایج ویندوز

نشانه راه حل
bunشناخته نمی شود PowerShell را دوباره باز کنید یا مسیر Bun را به PATH اضافه کنید.
پورت 3000 یا 5173 اشغال است فرآیند قبلی را ببندید یا مقدار پورت server را در config تغییر دهید.
مدل chat پاسخ نمی دهد ollama serveو ollama listرا بررسی کنید.
Whisper unavailable است برای transcription، bun run dev:whisperرا اجرا کنید؛ در غیر این صورت قابل چشم پوشی است.
تولید تصویر خطا می دهد Automatic1111 را با --apiاجرا و آدرس config را چک کنید.
دستورهای این صفحه برای PowerShell عادی نوشته شده اند و مستقیم اجرا می شوند.
