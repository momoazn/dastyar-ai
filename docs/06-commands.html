06 — دستورات

همه commandها از root اجرا می شوند مگر خلاف آن نوشته شده باشد.

توسعه

rtk bun install
rtk bun run dev
rtk bun run dev:web
rtk bun run dev:server
rtk bun run dev:whisper

کیفیت

rtk bun run lint:check
rtk bun run lint:fix
rtk bun run check-types
rtk bun run test
rtk bun run test:coverage

Build

rtk bun run build
rtk bun run build:fast
rtk bun run build:ci
rtk bun run build:windows
rtk bun run build:all
rtk bun --cwd apps/web build
rtk bun --cwd apps/server build

Release و package

rtk bun run build:release
rtk bun run build:release:windows
rtk bun run archive
rtk bun run package:source

archivesource zip می سازد و generated/runtime outputها را حذف می کند.

Database و config

rtk bun run db:generate
rtk bun run db:migrate
rtk bun run db:push
rtk bun run db:studio
rtk bun run config:generate
rtk bun run config:show
rtk bun run config:validate

Service lifecycle

rtk bun run start
rtk bun run stop
rtk bun run status

Assets

rtk bun run download:ffmpeg
rtk bun run download:ffmpeg:all
rtk bun run download:model

Verification پیشنهادی قبل از handoff

rtk bun run lint:check
rtk bun run check-types
rtk bun run test --force
rtk bun --cwd apps/web build
rtk bun --cwd apps/server build
rtk bun run archive
