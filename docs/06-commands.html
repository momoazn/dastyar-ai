03 — دستورات

همه commandها از root اجرا می شوند مگر خلاف آن نوشته شده باشد.

توسعه

bun install
bun run dev
bun run dev:web
bun run dev:server
bun run dev:whisper
دستور کاربرد
bun install نصب dependencyهای همه workspaceها از root.
bun run dev اجرای همه appها با Turbo؛ مناسب smoke test کامل.
bun run dev:web اجرای Vite/React web app.
bun run dev:server اجرای Bun/Hono API server.
bun run dev:whisper اجرای Go Whisper service.

کیفیت

bun run lint:check
bun run lint:fix
bun run check-types
bun run test
bun run test:coverage

Build

bun run build
bun run build:fast
bun run build:ci
bun run build:windows
bun run build:all
bun --cwd apps/web build
bun --cwd apps/server build

build:fastبرای feedback سریع development است. build:windowsخروجی Windows می سازد. build:ci برای verify قبل از تحویل مناسب است.

Release و package

bun run build:release
bun run build:release:windows
bun run archive

archivesource zip می سازد و generated/runtime outputها را حذف می کند.

Database و config

bun run db:generate
bun run db:migrate
bun run db:push
bun run db:studio
bun run config:generate
bun run config:show
bun run config:validate

بعد از تغییر schema، migration بسازید و روی دیتابیس local اجرا کنید. db:studioبرای inspect دستی داده ها مفید است. config runtime در config.jsonاست و نباید commit شود.

Service lifecycle

bun run start
bun run stop
bun run status

این دستورها برای binaryهای build شده هستند. اگر هنوز build نگرفته اید، اول bun run buildیا build هدفمند server/web را اجرا کنید. statusوضعیت endpointهای اصلی مثل server و Whisper را نشان می دهد.

Assets

bun run download:ffmpeg
bun run download:model

این دستورها assetهای لازم برای Whisper را دانلود می کنند. این فایل ها runtime artifact هستند و نباید وارد git یا source archive شوند.

Optional services

Service Default URL کاربرد
Ollama http://localhost:11434 chat، embedding و قابلیت های متنی local
LM Studio http://localhost:1234/v1 OpenAI-compatible local model server
Stable Diffusion WebUI http://localhost:7860 تولید تصویر
Whisper http://127.0.0.1:8080 transcription صوت

Verification پیشنهادی قبل از handoff

bun run lint:check
bun run check-types
bun run test --force
bun --cwd apps/web build
bun --cwd apps/server build
bun run archive

برای تغییر docs-only، bun run lint:checkکافی است. برای تغییر package، API، TypeScript، scripts یا build، کل checklist را اجرا کنید.
