01 — راه اندازی و اجرا

این صفحه مسیر استاندارد اجرای پروژه روی ماشین توسعه را توضیح می دهد.

پیش نیازها

  • Bun 1.3 یا جدیدتر
  • Go برای سرویس Whisper
  • Ollama یا LM Studio برای چت و قابلیت های متنی
  • Stable Diffusion WebUI برای تولید تصویر، در صورت نیاز
  • whisper.cpp و مدل های Whisper برای transcription کامل

نصب

rtk bun install

اجرای development

rtk bun run dev

برای اجرای جداگانه بخش ها:

rtk bun run dev:web
rtk bun run dev:server
rtk bun run dev:whisper

Config سرور

سرور از apps/server/config.jsonیا مقدارهای پیش فرض apps/server/src/config-schema.tsاستفاده می کند. 

rtk bun run config:generate
rtk bun run config:show
rtk bun run config:validate

مهم ترین کلیدهای config

کلید معنی پیش فرض
PORT پورت سرور 3000
DATABASE_FILE مسیر SQLite ./data.db
JWT_SECRET کلید امضای JWT باید در production تغییر کند
OLLAMA_BASE_URL آدرس Ollama http://localhost:11434
STABLE_DIFFUSION_BASE_URL آدرس Stable Diffusion WebUI http://localhost:7860
WHISPER_SERVER_URL آدرس سرویس Whisper http://127.0.0.1:8080
IMAGES_DIR ذخیره خروجی تصاویر ./generated-images
DOCUMENTS_DIR ذخیره فایل های آپلودی ./uploaded-documents

راه اندازی دیتابیس

rtk bun run db:migrate

schema در apps/server/src/database/schema/index.tsتعریف شده و migrationها در apps/server/src/database/migrationsهستند.
