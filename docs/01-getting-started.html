02 — راه اندازی local

این صفحه مسیر استاندارد اجرای پروژه روی ماشین توسعه را توضیح می دهد. برای Windows، صفحه راهنمای راه اندازی Windows مسیر کامل تری از نصب ابزارها تا اجرای اپ دارد.

پیش نیازها

  • Bun 1.3 یا جدیدتر
  • Go برای سرویس Whisper
  • Ollama یا LM Studio برای چت و قابلیت های متنی
  • Stable Diffusion WebUI برای تولید تصویر، در صورت نیاز
  • whisper.cpp و مدل های Whisper برای transcription کامل

ترتیب درست راه اندازی

  1. ابزارهای سیستم را نصب و نسخه ها را بررسی کنید.
  2. dependencyهای workspace را با bun installنصب کنید.
  3. config سرور را بسازید و validate کنید.
  4. migration دیتابیس را اجرا کنید.
  5. Ollama یا provider متنی را اجرا و حداقل یک مدل chat آماده کنید.
  6. در صورت نیاز Whisper و Stable Diffusion را آماده کنید.
  7. سرور و وب را اجرا و health را بررسی کنید.
  8. اولین کاربر را بسازید؛ این کاربر admin می شود.

نصب

bun install

نصب باید از root repo اجرا شود تا Bun workspace همه appها را ببیند. نصب جداگانه داخل apps/serverیا apps/webبرای شروع لازم نیست.

اجرای development

bun run dev

این دستور Turbo pipeline را اجرا می کند. برای توسعه روزمره معمولا بهتر است فقط سطحی را که تغییر می دهید جدا اجرا کنید.

برای اجرای جداگانه بخش ها:

bun run dev:web
bun run dev:server
bun run dev:whisper

Config واحد پروژه

همه بخش ها از یک فایل canonical استفاده می کنند: config.jsonدر ریشه repo. سرور، وب dev proxy، اسکریپت های start/status و سرویس Whisper همین فایل را می خوانند. فایل های .envیا config جداگانه داخل appها نباید برای تنظیمات runtime ساخته شوند. 

bun run config:generate
bun run config:show
bun run config:validate

مقدارهای پیش فرض در apps/server/src/config-schema.tsتعریف شده اند و نمونه قابل commit در config.example.jsonاست. فایل واقعی config.jsonlocal است و نباید commit شود.

مهم ترین کلیدهای config

کلید معنی پیش فرض
PORT پورت سرور 3000
DATABASE_FILE مسیر SQLite ./data.db
JWT_SECRET کلید امضای JWT باید در production تغییر کند
OLLAMA_BASE_URL آدرس Ollama http://localhost:11434
STABLE_DIFFUSION_BASE_URL آدرس Stable Diffusion WebUI http://localhost:7860
WHISPER_SERVER_URL آدرس سرویس Whisper http://127.0.0.1:8080
IMAGES_DIR ذخیره خروجی تصاویر ./generated-images
DOCUMENTS_DIR ذخیره فایل های آپلودی ./uploaded-documents

راه اندازی دیتابیس

bun run db:migrate

schema در apps/server/src/database/schema/index.tsتعریف شده و migrationها در apps/server/src/database/migrationsهستند.

چک سلامت بعد از اجرا

curl http://localhost:3000/health

پاسخ موفق باید statusبرابر okداشته باشد. اگر Whisper روشن نباشد، health آن unavailable می شود اما چت و تنظیمات عمومی همچنان قابل استفاده هستند.

آماده سازی هر قطعه

قطعه حداقل راه اندازی نشانه موفقیت
Server config:generate، db:migrate، dev:server /healthپاسخ JSON بدهد.
Web dev:webبعد از روشن بودن server صفحه login/register روی 3001باز شود.
Ollama ollama serveو ollama pull مدل ها در admin یا sync models دیده شوند.
Whisper download:ffmpeg، download:model، dev:whisper health سرور، Whisper را available نشان دهد.
Stable Diffusion اجرای Automatic1111 با --api http://localhost:7860پاسخ دهد.

ورود اولیه

اولین کاربر ثبت نام شده به صورت خودکار admin می شود. بعد از آن ساخت و مدیریت کاربران از پنل admin انجام می شود.

دستورهای مستندات برای توسعه دهنده عادی نوشته شده اند و مستقیم در shell اجرا می شوند.
