05 — قابلیت ها و مسیر تغییرات رایج

این صفحه هر feature را به فایل های اصلی آن وصل می کند.

Chat و RAG

  • وب: routes/chat/*, components/chat/*, hooks/use-ai-chat.ts.
  • سرور: routes/chat.ts, procedures/threads.ts, procedures/messages.ts.
  • RAG: procedures/documents.ts, services/processors/rag.ts, embeddings.ts.
  • مدل ها: procedures/llm-models.ts, repositories/llm-models.ts.

ترجمه

  • وب: routes/translation/*, components/translation/*.
  • سرور: procedures/translation.ts, repositories/translations.ts.
  • PDF translation از extractors و LLM helper استفاده می کند.

خلاصه سازی

  • وب: routes/summary/*.
  • سرور: procedures/summarize.ts, repositories/summaries.ts.
  • خروجی ها history دارند و قابل حذف هستند.

دستیار کد

  • وب: routes/code/*, lib/code-output.ts.
  • سرور: procedures/code.ts, repositories/code-runs.ts.
  • modeها شامل generate، explain، review و debug هستند.

تولید تصویر

  • وب: routes/image/*, components/image-generation/*.
  • سرور: procedures/images.ts, procedures/image-threads.ts.
  • Provider: services/ai-providers/stable-diffusion.ts.
  • فایل ها در IMAGES_DIRذخیره و از routeهای /api/imagesserve می شوند.

تبدیل صوت به متن

  • وب: routes/transcribe.tsx, hooks/use-transcription.ts, components/transcribe/*.
  • سرور Bun: procedures/transcribe.ts, services/ai-providers/whisper.ts.
  • سرویس Go: apps/whisper/main.go, internal/handler/transcribe.go.

Admin و settings

  • وب: routes/admin.tsx, components/admin/*.
  • سرور: procedures/admin.ts, repositoryهای admin/settings/models/ollama.
  • Feature toggles از system settings خوانده و در sidebar اعمال می شوند.

افزودن feature جدید

  1. schema و repository را در سرور اضافه کنید.
  2. procedure را در proceduresبسازید و در index.tsexport کنید.
  3. route و componentهای وب را اضافه کنید.
  4. متن فارسی را در lib/textsاضافه کنید.
  5. در صورت نیاز sidebar/navigation و feature toggle را آپدیت کنید.
  6. برای repository/procedure/hook تست focused اضافه کنید.
