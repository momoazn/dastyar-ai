03 — سرور

سرور با Bun، Hono، ORPC، Drizzle و SQLite ساخته شده است.

Entry points

فایل وظیفه
src/index.ts خواندن config، اجرای migrationها و start سرور
src/app.ts ساخت Hono app، middlewareها، health، static serving
src/routes/rpc.ts اتصال ORPC router به Hono
src/routes/chat.ts مسیر streaming chat با AI SDK
src/routes/images.ts serve/download تصویرهای تولید شده

ORPC router

apps/server/src/procedures/index.tsهمه procedureها را در appRouterترکیب می کند.

Namespace فایل کاربرد
auth auth.ts register، login، me، تغییر username/password
admin admin.ts کاربران، مدل ها، Ollama serverها، system settings
appConfig app-config.ts feature toggles و build info
models llm-models.ts لیست مدل های فعال و sync مدل ها
threads/messages threads.ts, messages.ts مدیریت thread و پیام های chat
documents documents.ts آپلود، attach، index و حذف سند
translations translation.ts ترجمه متن و PDF
summarize summarize.ts خلاصه سازی و history
code code.ts تولید، توضیح، review و debug کد
images/imageThreads images.ts, image-threads.ts تولید تصویر و threadهای تصویر
transcribe transcribe.ts مدل های Whisper و transcription

Auth و نقش ها

  • JWT در services/auth.tsساخته و validate می شود.
  • protectedProcedureنیاز به user معتبر دارد.
  • adminProcedureعلاوه بر user معتبر، نقش admin را لازم دارد.
  • اولین کاربر ثبت نام شده admin می شود.

دیتابیس

schema در src/database/schema/index.tsاست. migrationها در src/database/migrationsنگهداری و برای build با bundle-migrations.tsembed می شوند.

Repository داده
auth.ts users، password hash، profile update
threads.ts, messages.ts chat threads و messages
documents.ts document metadata و chunks
images.ts, image-threads.ts image generations و image threads
translations.ts, summaries.ts, code-runs.ts history قابلیت های ابزارها
ollama-servers.ts, llm-models.ts provider registry و models
system-settings.ts feature flags و تنظیمات admin

AI providers

  • ollama-provider.ts: Ollama، OpenAI-compatible و Ollama native endpoints.
  • lmstudio-provider.ts: LM Studio compatible API.
  • ollama-router.ts: انتخاب least-busy Ollama server.
  • stable-diffusion.ts: Stable Diffusion WebUI API.
  • whisper.ts: client سرویس Whisper.

فایل، RAG و پردازش

  • اعتبارسنجی فایل در lib/file-validation.ts.
  • storage سند و تصویر در services/storage.
  • استخراج متن PDF/DOCX/HTML/EML/RTF/XLSX در services/processors.
  • ساخت embedding و chunk retrieval در embeddings.tsو rag.ts.
