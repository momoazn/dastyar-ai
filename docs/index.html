Dastyar AI — مستندات پروژه

دستیار هوشمند local-first با وب اپ React، سرور Bun/Hono، دیتابیس SQLite با Drizzle، سرویس اختیاری Whisper، و اتصال به Ollama، LM Studio و Stable Diffusion.

اجزای اصلی

بخش مسیر وظیفه
وب apps/web رابط کاربری، routeها، فرم ها، چت، تنظیمات و پنل ادمین
سرور apps/server API، احراز هویت، دیتابیس، فایل ها، RAG و هماهنگی AI
Whisper apps/whisper سرویس Go برای تبدیل صوت به متن با whisper.cpp
اسکریپت ها scripts build، start/stop، status، دانلود asset و archive
مستندات docs راهنمای توسعه، معماری، عملیات و تحویل

شروع سریع

rtk bun install
rtk bun run dev

کیفیت و وضعیت فعلی

  • فرمت و lint با Ultracite/Biome کنترل می شود.
  • تست ها با Bun test اجرا می شوند؛ E2E فعلا عمدا حذف شده است.
  • Build وب warning بزرگ بودن chunk دارد؛ منبع اصلی syntax highlighting، Mermaid و KaTeX است.
  • Archive source با bun run archiveساخته می شود و خروجی های runtime را حذف می کند.
