07 — Whisper

سرویس Whisper یک سرویس Go کوچک است که فایل صوتی را از سرور دریافت می کند، با whisper.cpp تبدیل به متن می کند و نتیجه را به API اصلی برمی گرداند.

جایگاه در سیستم

وب فایل صوتی را به procedureهای transcribe در سرور می فرستد. سرور فایل را validate و ذخیره موقت می کند، سپس از client apps/server/src/services/ai-providers/whisper.tsبه سرویس Go درخواست می دهد. سرویس Go مدل local را load می کند و متن نهایی را به سرور برمی گرداند.

فایل های اصلی

مسیر وظیفه
apps/whisper/main.go خواندن config، اجرای HTTP server، health و graceful shutdown
apps/whisper/internal/handler/transcribe.go دریافت multipart upload، validation و پاسخ JSON
apps/whisper/internal/service/whisper.go اتصال به bindingهای whisper.cpp و اجرای transcription
apps/whisper/go.mod dependencyهای Go و binding whisper.cpp
whisper-models مدل های دانلود شده برای release/runtime

Config

config فقط از config.jsonریشه repo خوانده می شود. سرویس Go هنگام اجرا در dev یا dist مسیرهای config.json، ../config.jsonو ../../config.jsonرا بررسی می کند.

کلید معنی
WHISPER_SERVER_URL URL کامل سرویس؛ port از همین مقدار استخراج می شود.
WHISPER_MODEL_DIR مسیر پوشه مدل ها، مثلا ./models.
WHISPER_MODELS لیست مدل ها با comma؛ سرویس Go اولین مدل غیرخالی را استفاده می کند.
WHISPER_TIMEOUT_MS timeout سمت سرور API هنگام صدا زدن سرویس Whisper.

راه اندازی dev

bun run config:generate
bun run download:model
bun run dev:whisper

پس از اجرا، health را با آدرس داخل WHISPER_SERVER_URLچک کنید. اگر config را تغییر دادید، سرویس را restart کنید.

قرارداد API

Endpoint کاربرد
GET /health بررسی آماده بودن سرویس
POST /transcribe دریافت فایل صوتی multipart و برگرداندن متن

Build و release

build اصلی با bun run buildیا build هدفمند در scripts/build.tsانجام می شود. خروجی binary در distقرار می گیرد و مدل ها باید کنار release یا در مسیر تعریف شده در config موجود باشند.

نکات توسعه

  • مسیر happy path را از وب شروع کنید؛ UI فقط با سرور API صحبت می کند.
  • خطای file type، حجم، مدل گم شده و timeout باید پیام فارسی داشته باشد.
  • bindingهای whisper.cpp native هستند؛ خطای whisper.hیعنی dependency native آماده نیست.
  • برای تغییر مدل پیش فرض، اول config.example.jsonو docs را به روز کنید.
